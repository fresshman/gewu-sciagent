# 带容差的结果对比表模板

**容差必须在比较之前声明**：绝对 ___ + 相对 ___（或按指标逐项覆盖），
理由：____________。事后放宽要在 `change_records` 留痕，否则结论作废。

| 指标 | 口径（单位/聚合方式） | 论文声明 | 论文定位 | 复现实测 | 实测来源 | 绝对差 | 容差 | 判定 | 差异性质 |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  | PASS / FAIL / UNVERIFIABLE | 数值波动 / 方法性差异 / 不可核验 |

- 口径示例：RMSE 是逐折均值还是合并 OOF；std 是总体还是样本；R² 用哪个库的实现。
- 判定为 FAIL 的每一行必须进入 `attribution.json` 的归因条目。
- 图/曲线只作辅助证据：数值优先，不用视觉相似度代替指标核验。
