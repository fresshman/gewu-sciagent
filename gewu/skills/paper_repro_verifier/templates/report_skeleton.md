# 复现报告骨架（report.py 会自动填实）

1. **材料定位**：清单、来源/版本、缺失登记
2. **环境检查**：依赖/硬件/种子、可在他机重建的快照、与论文声明的不一致
3. **参数复原**：三源对齐表、冲突裁决、`source_class` 依据
4. **代码运行**：实际命令、退出码、stdout/stderr、耗时
5. **结果比较**：事前容差、逐指标 PASS/FAIL/UNVERIFIABLE、图与原图对比
6. **差异归因**：五类假设、验证动作、已证实的结论与证据定位
7. **复现结论**：分级 + 依据 + 不确定性 + 可人工接管位置
8. **复核路径**：产物列表、commit、环境快照、数据版本、重跑命令

> 结论必须能被他人按记录独立重跑；未报告/无法判断/材料冲突分别写明，不写成事实。
