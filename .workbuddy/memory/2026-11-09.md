### 关键教训（勿重复）
- **编译退出码 0 ≠ 中文没丢**：article+inputenc+T1 编中文 → 13 处 Missing character，
  退出码正常、页数正常，PDF 只剩 30 个 ASCII 字符。必须解析 `Missing character` 并作为失败判据。
- **PDF 二进制哈希不可做快照比对**：内嵌 /CreationDate，同一 tex 连编两次字节必不同
  （实测 d9f2.../b558...），但正文一致。指纹 = 抽文本→压空白→日期归一→sha256。
- **`get_images()` 返回 0 不代表没图**：矢量插图不是位图，必须渲染页面看。
- **overfull 三处**：不可断行的数学数组/集合、长路径（改 `\path`，可在 / 处断行）。
