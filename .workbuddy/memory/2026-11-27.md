**PNG 渲染方法**（`output/scratch/svg_to_png.mjs`，scratch 不入库）：用 web/node_modules 的
playwright-core（ESM 绝对路径导入）+ Edge 无头，把 SVG 内容**内联**进 HTML 再对 `<svg>` 截图；
`file://` 图片在 `setContent` 里会被浏览器安全策略挡住，必须内联。SVG 内 `var(--font-sans)`
在独立渲染时不生效，须换成真实字体栈（Segoe UI, Microsoft YaHei, PingFang SC）。
